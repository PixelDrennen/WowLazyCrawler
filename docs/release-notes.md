LazyCrawler now includes automatic desktop and addon updates, live data transfers, and clearer market-readiness diagnostics.

Install this updater-enabled RPM once using Fedora's installer (or replace your AppImage). Future stable releases download inside the app and install when you quit the desktop app or choose Restart and install. RPM upgrades may show Fedora's normal administrator authentication prompt.

Keep LazyCrawler open with your WoW folder configured. Both addons install/update automatically while WoW remains open; /reload applies new addon code. No ZIP extraction or full game restart is needed.

For data without a reload: use Copy live market data in the app, then /lc import and paste in WoW. For current inventories without logging out, use /lc export, Ctrl+C, then Import copied character capture in the app. These explicit clipboard transfers apply data immediately without executing imported code. The file bridge remains available at normal reload/logout; WoW does not provide a silent arbitrary-HTTP background link to desktop apps.

SavedVariables and application data are preserved. Update preferences, progress, installed versions, and errors appear in Addon connection. Native WoW and Fedora KDE upgrade acceptance remain manual validation; automated tests do not substitute for native verification.
